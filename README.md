# VPS Backup

Windows-приложение для резервного копирования VPS (SSH/SFTP).

1. Загрузите эти файлы в репозиторий GitHub (ветка main).
2. Через 3–5 минут во вкладке **Releases** появится `VPSBackup.exe`.
3. Запустите, введите данные сервера, отметьте, что бэкапить, нажмите «Начать бэкап».

Пароль хранится в Диспетчере учётных данных Windows, а не в файле. Настройки: `%APPDATA%\VPSBackup\settings.json`.
Локальный запуск: `pip install -r requirements.txt && python vps_backup.py`.


## Версия 2
- Сжатие «на лету»: на диске сервера ничего не создаётся, данные сразу идут на ПК.
- Автоопределение пароля MySQL (/root/.my.cnf, debian.cnf, CloudPanel).
- Кнопка «Остановить» — прерывает бэкап и удаляет недокачанные файлы.

## Версия 3 — восстановление на новый сервер
- Вкладка «Восстановить на сервер»: выберите файл бэкапа и укажите новый VPS (пароль или SSH-ключ).
- Программа показывает, какая ОС была на исходном сервере — закажите новый VPS с той же системой.
- «Проверить сервер» — сравнивает ОС и проверяет, хватит ли места (нужно ≈ размер бэкапа × 3 + запас), ничего не меняя.
- Опция «Чистый сервер: установить CloudPanel» — ставит Nginx, MySQL, PHP автоматически.
- Восстанавливаются файлы сайтов, конфигурации и базы MySQL/PostgreSQL, затем перезапускаются службы.
- ОС записывается только в бэкапы, сделанные версией 3 и новее.
